# Agent Onboarding Policy

For every new agent joining the collective. Read this before doing anything else.

## 1. Check in on arrival

- Read `Usage Instructions.md` and the 5 most recent notes in this folder first.
- Then leave an intro note named `YYYY-MM-DD-agent-<yourname>-intro.md` stating: your name, your model, your role, who operates you, and what you can and can't do.

## 2. Read before you write

- Check for newer notes before acting, so you don't redo or contradict another agent's work.

## 3. Dated notes, one per task

- Name files `YYYY-MM-DD-topic.md` (date first, short topic).
- Never edit or delete another agent's notes. Corrections go in a new dated note.

## 4. Identity on everything

- Every note carries: agent name, role, date. No anonymous writes.

## 5. No secrets, ever

- No passwords, API keys, tokens, or credentials in this folder. Ever.

## 6. Cost tracking lives with the launcher

- Agents cannot see their own token usage (proven in testing). Whoever spawns an agent is responsible for logging its cost — model, tokens in/out, timestamp — in a dated note.

## 7. Humans break ties

- If two agents disagree, the human decides. Agents never override each other, and a note never overrides the human's latest message.

## 8. Leaving

- A retired agent leaves a final note stating it's done and where its work stands.

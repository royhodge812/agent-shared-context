How to read this board

Every task sits in exactly one stage. A stage only changes when a real packet moves — see the rule box below.

Assigned

↓
2

With agent via Roy

Roy pasted the packet into the agent’s own chat and is awaiting its return. This is the only stage that means an agent is actually working.

↓

↓

Verifying

↓

The task needs Roy’s yes before anything else happens.

Blocked / Not dispatched

A separate lane: the task was flagged and is awaiting Roy’s instruction. It is not in the pipeline and no agent has it.

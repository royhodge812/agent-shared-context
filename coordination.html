How coordination happens regularly

Not a live feed — the standing rhythm every task follows, every time.

Roy assigns→ A-01 briefs a packet→ Roy pastes it→ Agent does the work→ Roy pastes the reply back→ A-01 verifies→ Roy approves→ Dated, signed note→ Drive + GitHub mirror

Every task

  • Roy → Muse: the job starts with Roy, in plain words.
  • Muse → packet: objective, role, inputs, deliverable, acceptance criteria — nothing vague travels.
  • Roy carries it: Roy pastes the packet to the chosen agent, and pastes the reply back. There is no other route.
  • Muse verifies: output is checked against the criteria and the Drive/GitHub record; gaps get flagged, not smoothed over.
  • Record closes the loop: a dated, signed note lands in Drive and is mirrored to GitHub.

Every roster change

  • When the roster or a verified status changes, the Dashboard, Registry, and GitHub Pages are re-exported and re-pushed so all three agree.
  • Drive (Agent-Coordination) is the live record; GitHub (agent-shared-context) is the backup mirror — never edited as the source of truth.
  • A new agent starts as Awaiting and only becomes Verified after a full check-in that A-01 confirms and Roy sees.

Standing rules

  • Roy's yes, every time: no agent spends, sends, posts, or files without Roy's explicit yes on that specific item. Rank never replaces it.
  • No secrets ever in shared context — no passwords, keys, or private data in Drive, GitHub, or any note.
  • Read before writing. Corrections go in a new dated note; nobody edits or deletes another agent's notes.
  • Ties: Roy breaks them. Between agents, higher rank decides; at the same rank, A-01 as Coordinator decides — then it still comes back to Roy if he says so.

Next regular step — Roy's part

  • Give Muse the next task, in your own words.
  • Take the packet Muse writes and paste it to the agent it names.
  • When that agent answers, paste the reply back to Muse.
  • Approve — or overrule — what Muse verifies.
  • Done: Muse records it as a dated, signed note in Drive and mirrors it to GitHub.

## Conflict rules

1. Roy overrules everyone.
2. Otherwise, the higher rank wins.
3. Same rank: the Coordinator (A-01) decides.
4. If still unclear, it goes to Roy — not to whoever spoke last.

Rank is about decision authority and keeping one true record. It is not a rating of intelligence or value.

## Shared-context rules

1. Read before writing. Check the latest shared notes before starting work.
2. Leave a dated note per task. Sign every note with your ID, handle, and timestamp.
3. Never edit or delete another agent's notes. Corrections go in a new dated note.
4. No secrets ever — no passwords, keys, tokens, or private IDs in shared context.
5. Humans break ties. The Operator is the final word.
